@app.route("/salut", methods=["GET", "POST"]) def salut(): if request.method == "POST": prenom = request.form.get("prenom", "inconnu") ville = request.form.get("ville", "nulle part") else: prenom = request.args.get("prenom", "inconnu") ville = request.args.get("ville", "nulle part") return f"Bonjour {prenom}, qui vient de {ville} ! (reçu en {request.method})" action="/salut" : l'URL où le formulaire envoie les données. name="prenom" : le nom du paramètre qui sera envoyé. Ajoutez ces deux routes dans flask_app.py : @app.get("/formulaire") def formulaire(): return render_template("formulaire.html") @app.get("/salut") def salut(): prenom = request.args.get("prenom", "inconnu") ville = request.args.get("ville", "nulle part") return f"Bonjour {prenom}, qui vient de {ville} !" Commit, visitez /formulaire, remplissez-le et envoyez-le. Regardez bien la barre d'adresse. Partie B — Le même formulaire en POST Dans formulaire.html, remplacez method="get" par method="post". Dans flask_app.py, modifiez la route /salut : @app.route("/salut", methods=["GET", "POST"]) def salut(): if request.method == "POST": prenom = request.form.get("prenom", "inconnu") ville = request.form.get("ville", "nulle part") else: prenom = request.args.get("prenom", "inconnu") ville = request.args.get("ville", "nulle part") return f"Bonjour {prenom}, qui vient de {ville} ! (reçu en {request.method})" Pour une requête POST, les données se lisent dans request.form au lieu de request.args. Commit, puis renvoyez le formulaire. Regardez à nouveau la barre d'adresse.
